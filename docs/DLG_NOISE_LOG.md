# 가우시안 노이즈 방어 실험 기록

## 1. 실험 목적
DLG 공격자가 관찰하는 단일 이미지 그래디언트에 가우시안 노이즈를 추가했을 때 복원 품질 변화를 비교한다.

## 2. 코드 및 조건
- 코드: `security/gradient_noise.py`, `experiments/dlg_noise_experiment.py`
- 모델: TinyDLGNet (단일 선형층; 실제 팀 FedAvg CNN과는 별도)
- 이미지: synthetic (8×8 RGB) 또는 CIFAR-10 (32×32 RGB) 한 장
- 고정 조건: 이미지 ID, 모델 초기 가중치, 난수 시드, 복원 초기값, 반복 횟수, 학습률
- 변화 조건: 그래디언트에 더하는 가우시안 노이즈의 표준편차 `std` (0, 0.01, 0.1)
- 노이즈 적용 위치: 클라이언트가 단일 이미지 그래디언트 계산한 직후, 공격자가 관찰하기 전
- 공격 입력: 동일한 모델 가중치 + 해당 조건의 관측 그래디언트; **원본 이미지/정답은 공격에 주지 않음**
- 평가: 공격 종료 후 원본과 복원 이미지의 MSE, 레이블 추정, 그래디언트 매칭 손실

가우시안 노이즈 방어 구현 및 실험 결과

실험 목적

DLG 공격에서 그래디언트에 가우시안 노이즈를 추가했을 때 원본 이미지 복원 성능에 미치는 영향을 분석하였다.

실험 환경

Python 3.13.3

입력 데이터: 8×8 합성 RGB 이미지

DLG 최적화 반복 횟수: 60회

노이즈 표준편차: 0, 0.01, 0.1

자동 테스트: 20개 모두 통과

노이즈가 없는 경우보다 표준편차 0.1을 적용한 경우 이미지 복원 MSE가 약 47.3배 증가하였다. 이를 통해 본 실험 조건에서는 가우시안 노이즈가 DLG 이미지 복원 정확도를 저하시키는 효과가 있음을 확인하였다.

다만 모든 조건에서 레이블 3이 추정되었으며, 단일 합성 이미지와 소형 모델에 대한 결과이므로 개인정보 보호 효과를 일반화할 수는 없다.

후속 작업

실제 CIFAR-10 이미지에서 DLG 복원과 노이즈별 MSE 비교를 수행하고, 여러 이미지와 시드로 실험을 반복할 예정이다.
